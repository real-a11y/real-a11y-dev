    text "supports Storybook 9.x, 10.x and 11.x with React 18 or React 19; its own suite runs on React 19. If you hit"

  heading "React 19 — pin the JSX runtime" (level 2)
  paragraph
    text "Storybook externalizes"
    code "react"
    text "for addon manager bundles but does"
    strong "not"
    text "externalize"
    code "react/jsx-runtime"
    text "— still true as of Storybook 11's manager globals map. When Vite's esbuild falls back to the classic JSX transform (which it does for some source files under React 19), story files emit"
    code "React.createElement(...)"
    text "calls that fail with"
    code "ReferenceError: React is not defined"
    text "— because automatic runtime is the default for React 19 projects and classic transform needs"
    code "React"
    text "in scope."
  paragraph
    text "The one-line fix lives in"
    code ".storybook/main.ts"
    text ":"
  button "Copy Code"
  code "// .storybook/main.ts import type { StorybookConfig } from "@storybook/react-vite"; import { mergeConfig } from "vite"; const config: StorybookConfig = { stories: ["../src/**/*.stories.@(ts|tsx)"], addons: ["@real-a11y-dev/storybook-addon"], framework: { name: "@storybook/react-vite", options: {}, }, // Force esbuild's automatic JSX runtime on source .tsx files — matches // the React 19 / Next.js default so stories don't need to import React. async viteFinal(config) { return mergeConfig(config, { esbuild: { jsx: "automatic", jsxImportSource: "react" }, }); }, }; export default config;"
  paragraph
    text "No source-file changes required — stories can keep writing JSX without"
    code "import React from "react""
    text "."
