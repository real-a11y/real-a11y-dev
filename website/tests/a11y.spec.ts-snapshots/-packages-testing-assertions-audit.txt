  heading "assertUniqueInteractiveNames(root)" (level 2)
    code "assertUniqueInteractiveNames(root)"
  paragraph
    text "Throws if two controls of one role share an accessible name, so that a screen-reader user who hears only the name, in the Tab order or in a list of the page's buttons or links, can't tell them apart. The rule is"
    code "unique-interactive-names"
    text ", a"
    code "warning"
    text "in"
    code "collectFindings"
    text ": no specification requires unique names, so it is best practice (WCAG 2.4.6 Headings and Labels, 2.4.9 Link Purpose (Link Only)), not a conformance failure."
  list
    listitem
      strong "Buttons, links, checkboxes and switches"
      text "are compared across the whole page, whichever landmark or region they sit in."
    listitem
      strong "Radios, options, tabs, menu items and tree items"
      text "are compared only within their own container (a"
      code "radiogroup"
      text "or"
      code "<fieldset>"
      text ", a list box or"
      code "<select>"
      text ", a tab list, a menu, a tree's level), which a screen reader announces as focus enters it. The same "Yes" radio under two questions passes; two "Large" radios in one group don't. A radio in no group is compared across the page."
    listitem
      strong "Text fields aren't compared"
      text ": a billing and a shipping fieldset can each have a "City"."
    listitem
      strong
        text "Links to the same"
        code "href"
        text "don't count"
      text ": they are one destination, and so are a path and an absolute URL with that path ("
      code "/docs"
      text "and"
      code "https://example.com/docs"
      text "). Links of one name that go to two places are all reported. A"
      code "href="#""
      text "or"
      code "javascript:"
      text "link goes nowhere in particular, so two "Delete" links with"
      code "href="#""
      text "are reported."
    listitem
      strong "The comparison ignores case, spacing and states"
      text "(an expanded and a collapsed "Options" are two "Options"), and ignores"
      strong "descriptions"
      text ": an"
      code "aria-describedby"
      text "that differs doesn't make two names unique, because the Tab order and an elements list don't read it."
    listitem
      strong "Each frame is compared on its own"
      text "in a native tree, and so is each player or field that draws controls of its own: every"
      code "<video controls>"
      text "has a "play" and every date input a "Show date picker" in Chromium's tree, and no page can rename them."
    listitem
      text "Unnamed controls are"
      code "assertNoUnlabeledInteractive"
      text "'s to report, not this rule's."
