  heading "Saved session (recommended)" (level 2)
  heading "1. Save the session" (level 3)
  paragraph
    text "Run"
    code "login"
    text "once. It opens a"
    strong "visible"
    text "browser — log in by hand, and MFA, SSO, and passkeys all work, because a person is driving. Then press"
    strong "Enter"
    text "in the terminal to save."
  button "Copy Code"
  code "real-a11y login https://app.example.com --save auth.json"
  button "Copy Code"
  code "Log in in the browser window, then press Enter here to save. saved session state to /path/to/auth.json audit a page on https://app.example.com with it: real-a11y audit <url> --storage-state auth.json"
  paragraph "Accept cookie banners before pressing Enter"
  paragraph "If the site shows a cookie-consent dialog, accept or dismiss it in the login window before saving — otherwise the consent cookie isn't in your session and the banner reappears (and can dominate the audited tree) on every later run."
  heading "2. Audit with it" (level 3)
  paragraph "Pass the file to any browser command:"
  button "Copy Code"
  code "real-a11y audit https://app.example.com/dashboard --storage-state auth.json real-a11y tree https://app.example.com/settings --storage-state auth.json"
  paragraph "Give single-page apps time to hydrate"
  paragraph
    text "A logged-in SPA reads the session, calls its API, and renders — all after the initial load. If you capture a half-rendered or redirected view, settle it:"
    code "--wait-until networkidle --settle 3000"
    text "."
  heading "Origin pinning" (level 3)
  paragraph
    text "When a session is loaded, auditing is"
    strong "pinned to the origin you asked for"
    text ". If a page redirects off that origin, extraction is refused (exit"
    code "2"
    text ") rather than silently auditing wherever it landed:"
  button "Copy Code"
  code "real-a11y: error: Refusing to audit https://elsewhere.example: not an allowed audit origin under an authenticated session (a redirect may have left the intended site). hint: the page redirected off the audited origin; pass --audit-origin <origin> if that's expected."
  paragraph "This is a safeguard: a saved session carries live cookies, and a stray or hostile redirect to another cookie-matching origin could otherwise pull an unintended authenticated page into your report. If the redirect is legitimate — an SSO bounce that ends on a second origin — allow it explicitly:"
  button "Copy Code"
  code "real-a11y audit https://app.example.com/dashboard \ --storage-state auth.json --audit-origin https://auth.example.com"
  paragraph
    text "Refusal is also a useful signal: it usually means the"
    strong "session expired"
    text "and the site bounced you to a login page. Re-run"
    code "login"
    text "to refresh"
    code "auth.json"
    text "."
  paragraph
    text "The pin covers the page's"
    code "<iframe>"
    text "s as well. A frame whose document comes from an origin you didn't allow is not read — its"
    code "Iframe"
    text "row stays empty — since it would carry the same cookies into your report, and a step can't act inside it. A"
    code "srcdoc"
    text ","
    code "about:blank"
    text "or"
    code "data:"
    text "frame holds the page's own markup and is read. Add the frame's origin with"
    code "--audit-origin"
    text "to include it."

  heading "Attach to your logged-in browser (--cdp)" (level 2)
    code "--cdp"
  paragraph
    text "For a one-off — or an app whose auth lives in"
    code "sessionStorage"
    text ", which a saved session can't capture — skip the file and attach to a Chrome you're already signed into. Start Chrome with remote debugging"
    strong "on a throwaway profile"
    text ", log in, then point the tool at it:"
  button "Copy Code"
  code "chrome --remote-debugging-port=9222 --user-data-dir=/tmp/a11y-cdp real-a11y audit https://app.example.com/dashboard --cdp http://localhost:9222"
  paragraph
    text "The session comes from that browser, not from a file: if your"
    code "a11y.config.json"
    text "sets"
    code "storageState"
    text "(or"
    code "device"
    text ","
    code "viewport"
    text ","
    code "headful"
    text "),"
    code "--cdp"
    text "ignores it and says so on stderr:"
  button "Copy Code"
  code "real-a11y: warning: --cdp ignores `storageState` from a11y.config.json — it uses the attached browser's own session. a browser that isn't signed in (a fresh remote one, say) audits the logged-out page."
  paragraph
    text "The warning doesn't change the exit code. An empty"
    code "--cdp """
    text ", which is what an unset CI variable gives you, is an error (exit"
    code "2"
    text ") rather than a fresh, signed-out browser."
  paragraph "Use a dedicated profile for CDP"
  paragraph
    text "Attaching over CDP connects to whatever Chrome is on that port —"
    strong "including your everyday browser and its logged-in sessions"
    text "(email, banking). Always launch a separate profile with its own"
    strong "--user-data-dir"
    text ", never enable remote debugging on your main profile."
  paragraph
    text "The MCP server uses the same mechanism via the"
    code "REAL_A11Y_MCP_CDP"
    text "environment variable — see the"
    link "MCP configuration"
    text "."
  heading "Security" (level 2)
  paragraph
    text "The saved session file is a"
    strong "credential"
    text "— treat"
    code "auth.json"
    text "like a password:"
  list
    listitem
      strong "Never commit it."
      text "It holds live session tokens."
      code "login"
      text "writes it with owner-only permissions and warns if it lands un-gitignored inside a repo — add it to"
      code ".gitignore"
      text "."
    listitem
      strong "Use a dedicated low-privilege test account"
      text ", not your admin or personal account. Anyone (or any agent) with the file can read every page that session can reach."
    listitem
      strong "It's short-lived"
      text "— it stops working when the site's session expires."
      code "login"
      text "is the re-auth path."
    listitem
      strong
        code "sessionStorage"
        text "is not captured."
      text "Apps that keep auth there will land logged-out after a saved-session restore — use"
      code "--cdp"
      text "for those."
  heading "In CI" (level 3)
  paragraph "Provision the file from a secret at job start; hosted runners are ephemeral, so no cleanup step is needed:"
  button "Copy Code"
  code "- run: printf '%s' "$A11Y_STORAGE_STATE" > auth.json env: A11Y_STORAGE_STATE: ${{ secrets.A11Y_STORAGE_STATE }} - run: npx real-a11y audit https://staging.example.com/dashboard --storage-state auth.json"
  paragraph
    text "Rotate by re-running"
    code "login"
    text "locally and updating the secret."
  paragraph "Never run untrusted config with a live session"
  paragraph
    text "Do not audit a pull-request-controlled URL or config while a secret-provisioned session is loaded (e.g. under a"
    strong "pull_request_target"
    text "trigger). A PR could point the audit at an attacker page that redirects into your authenticated site. Keep the audit target a literal in the workflow — origin pinning then fails closed on any redirect elsewhere."
