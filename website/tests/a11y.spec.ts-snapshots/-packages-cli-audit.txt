  paragraph
    text "Accessibility is a property of the"

    text "downloads"
    link "Chrome for Testing"
    text "— Google's versioned, non-auto-updating Chrome build — into the CLI's own cache and uses it for every launched session from then on. Run it once; re-runs are instant no-ops."

  heading "Track regressions across a PR" (level 2)
  paragraph
    text "The flagship CI feature: snapshot one page or a whole set into a diffable artifact, then diff two of them and fail the build only on"
    strong "new"
    text "findings."
  button "Copy Code"
  code "# a single page — a URL positional, like every other command real-a11y snapshot https://example.com -o base.json # or a whole set (base branch, then PR) real-a11y snapshot --config a11y.config.json -o base.json real-a11y snapshot --config a11y.config.json -o pr.json real-a11y diff base.json pr.json # exit 1 only on NEW findings real-a11y diff base.json pr.json -f md # a PR-comment-ready summary"
  paragraph
    text "The diff is"
    strong "finding-identity-aware"
    text ", not a line diff: each finding carries a stable"
    code "v1:"
    text "fingerprint, so a renumbered"
    code ":nth-of-type"
    text "locator, a re-indented subtree, or an inserted sibling is"
    strong "not"
    text "a change — only an actual new / changed / fixed violation is. Pre-existing debt never blocks a PR (REMOVED and CHANGED don't gate), and the config is strict and fail-closed — a typo'd key is an error, so a mistake can't silently un-gate CI."
