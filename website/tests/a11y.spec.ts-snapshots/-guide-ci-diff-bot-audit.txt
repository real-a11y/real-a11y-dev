main
  heading "CI A11y Diff Bot" (level 1)
  paragraph "A GitHub Actions workflow that comments on each pull request with what changed in the accessibility of the pages you list: new and fixed findings, plus structural changes such as a heading level, a renamed button or a removed landmark."
  paragraph
    text "It runs two"
    link "@real-a11y-dev/cli"
      code "@real-a11y-dev/cli"
    text "commands."
    code "real-a11y snapshot"
    text "audits a set of pages into one JSON file, and"
    code "real-a11y diff"
    text "compares two of those files. The diff matches findings by a stable fingerprint rather than by line, so re-indented markup or a renumbered selector doesn't show up as a change."
  heading "How it works" (level 2)
  button "Copy Code"
  code "PR opened / pushed │ ┌────┴─────────────────┐ │ │ ▼ ▼ Snapshot (base) Snapshot (PR) - checkout main - checkout HEAD - install deps - install deps - start server - start server - real-a11y - real-a11y snapshot snapshot │ │ └────────┬──────────┘ ▼ real-a11y diff + comment (updated on every push)"
  paragraph
    text "The two snapshot jobs run in parallel and upload"
    code "base.json"
    text "and"
    code "pr.json"
    text ". A third job compares them and creates or updates a single comment on the PR."

  heading "3. Add the workflow" (level 2)
  button "Copy Code"
  code "# .github/workflows/a11y-diff.yml name: A11y diff on: pull_request: branches: [main] permissions: contents: read jobs: snapshot: name: Snapshot (${{ matrix.side }}) runs-on: ubuntu-latest strategy: matrix: side: [base, pr] steps: - uses: actions/checkout@v7 with: # base: the branch the PR targets. pr: empty, so the PR's merge commit. ref: ${{ matrix.side == 'base' && github.base_ref || '' }} - uses: actions/setup-node@v7 with: node-version: 22 cache: npm - run: npm ci - run: npx playwright install chromium --with-deps # Build and start your app. These are the steps to adapt. - run: npm run build - run: npx serve dist -l 3000 & - run: npx wait-on http://localhost:3000 --timeout 120000 - run: npx real-a11y snapshot -o ${{ matrix.side }}.json - uses: actions/upload-artifact@v7 with: name: ${{ matrix.side }}-snapshot path: ${{ matrix.side }}.json if-no-files-found: error diff: name: Diff & comment needs: snapshot runs-on: ubuntu-latest permissions: contents: read pull-requests: write # create and update the comment steps: # The base branch, not the PR: nothing from the PR runs with the write token. - uses: actions/checkout@v7 with: ref: ${{ github.base_ref }} - uses: actions/setup-node@v7 with: node-version: 22 cache: npm - run: npm ci # diff only reads two files: no browser needed - uses: actions/download-artifact@v8 with: pattern: "*-snapshot" merge-multiple: true # The full diff goes to the job log, and a shorter copy to the comment. - run: npx real-a11y diff base.json pr.json --explain --fail-on never - run: npx real-a11y diff base.json pr.json --format md --explain --fail-on never --max-pages 5 --max-lines 20 -o comment.md # A pull request from a fork gets a read-only token, so skip the comment there. - if: github.event.pull_request.head.repo.full_name == github.repository uses: actions/github-script@v9 with: script: | const fs = require("fs"); const MARKER = "<!-- real-a11y-diff -->"; const { owner, repo } = context.repo; const issue_number = context.issue.number; const run = `${context.serverUrl}/${owner}/${repo}/actions/runs/${context.runId}`; const body = `${MARKER}\n${fs.readFileSync("comment.md", "utf8")}\n[Full diff in the job log](${run})`; // Every page of comments: on a busy PR ours can be past the first, // and missing it posts a second comment on every push. const comments = await github.paginate(github.rest.issues.listComments, { owner, repo, issue_number, per_page: 100, }); // Match the bot AND a marker on the first line: a page's text can // quote the marker, and it ends up inside the comment body. const mine = comments.find( (c) => c.user?.login === "github-actions[bot]" && c.body?.startsWith(MARKER), ); if (mine) { await github.rest.issues.updateComment({ owner, repo, comment_id: mine.id, body }); } else { await github.rest.issues.createComment({ owner, repo, issue_number, body }); }"
  paragraph
    text "Only the diff job can write to the PR, and it checks out the base branch, so the PR's install and build scripts never run with that permission. On a pull request from a fork, GitHub gives the workflow a read-only token whatever it asks for, so the comment step is skipped there and the diff is only in the job log."

    code "--ignore-view-line '<regex>'"
    text "to both diff steps so it doesn't read as a change."

  heading "What the comment looks like" (level 2)
  paragraph
    text "For a PR that drops an input's label, turns an"
    code "h2"
    text "into an"
    code "h3"
    text ", and stops pre-checking a newsletter box,"
    code "diff"
    text "writes this (shortened):"
  button "Copy Code"
  code "### Accessibility diff **Findings** (gate CI): 1 new · 0 changed · 0 fixed **Structure** (advisory): changed on 1 page — new or reordered headings, landmarks, or tab stops #### Home - ❌ **new** `no-unlabeled-interactive`: Unlabeled interactive element: textbox <input> **Structure (advisory — never blocks merge):** - Heading level changed: "Setup" h2 → h3 - Interactive element removed: textbox "Email" - Interactive element added: textbox (no accessible name) - States changed: checkbox "Newsletter": checked → checked=false _tree_ ```diff @@ -1,7 +1,7 @@ main heading "Shop" (level 1) heading "Plans" (level 2) - heading "Setup" (level 2) - textbox "Email" - checkbox "Newsletter" {checked} + heading "Setup" (level 3) + textbox + checkbox "Newsletter" {checked=false} button "Subscribe" ```"
  paragraph
    strong "Findings"
    text "come from the seven audit rules and can fail the build."
    strong "Structure"
    text "covers changes that break no rule, and never fails it. When nothing changed, both lines say so. A line whose only change is its"
    code "{…}"
    text "states block (a box checked or unchecked, a disclosure collapsed, a description changed) reads as one"
    code "States changed:"
    text "statement."
  paragraph
    text "Tab order isn't compared:"

    text "reads Chromium's accessibility tree, which has no tab order, so every diff notes that the tabs view wasn't compared. For keyboard order, use"
